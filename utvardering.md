Vi har byggt ett webbapp i react med typescript där man kan lägga till och ta bort uppgifter/todos.

Vi kom igång fort och försökte förstå uppgiften tillsammans och gjorde user stories samt gick igenom git, github issues och projects.
Mob progammering var rörigt i början eftersom vi hade olika erfarenhet och olika viljor. Det blev mycket diskussioner. Senare i projektet så gick det lättare att samarbeta eftersom vi lärde känna varandra bättre. 

Vi hade lite problem med att hämta branch från remote till lokalt och även när vi skulle göra npm install. En del av problemet var pga .gitignore så vi la till rätt filändelser i den och då fungerade det bättre. Vi arbetade mycket med git kommandon istället för gränssnittet.

I projektet arbetade vi med en dev-branch som vi gjorde feature-branches utav och sen gjorde vi PR till dev och i sist till main.
När vi började dagen skapade vi ny branch med kommando i terminalen. Från början arbetade vi med egna branches som vi mergade till dev innan nästa person tog över i sin branch. Men senare gick vi över till att arbeta i samma branch vilket var smidigare för det här projektet som var så litet.
Under projektet hade vi flera merge konflikter som vi löste tillsammans. För det mesta gick det att använda github men en konflikt var för "komplicerad" att lösa och då fick vi lösa det manuellt.
Vi fick också en större förståelse för vs code och git/github under projektets gång vilket underlättade senare.

Vid mob programmering hade det varit bra att låta den som programmerar skriva klart innan vi andra börjar diskutera själva koden och vad som kan förbättras/ändras i den.
Senare under projektets gång började vi också använda timer när vi programmerade vilket gjorde det lättare att hålla tiderna.
